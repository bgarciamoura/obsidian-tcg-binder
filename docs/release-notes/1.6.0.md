# TCG Binder 1.6.0

Bought the missing cards? Register them right there.

## Added

- **Add missing deck cards to a collection**: every row in the deck view's "Missing from collection" list now has a + action that opens the add-card dialog with the quantity prefilled to exactly what's missing — pick the collection, variant and condition and confirm. The missing list and its cost update immediately. Adding to a wishlist works too, for marking cards you still plan to buy.
