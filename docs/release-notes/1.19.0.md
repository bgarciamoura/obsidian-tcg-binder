# TCG Binder 1.19.0

Know where every on-the-way card is coming from.

## Added

- **Purchases with a source**: the 🛒 dialog is now a purchase list — one line per purchase with quantity and where/from whom you bought it (store, marketplace, a friend…). Buying 2 copies from one seller and 1 from another stays legible: the missing list shows "4 bought, on the way (2 Liga ABC · 1 João · 1 OLX)".
- Registering an arrival with the **+** button burns purchases oldest-first, so the remaining notes keep describing the copies still in transit; edit the list via 🛒 whenever a different package arrives first.

## Changed

- Deck frontmatter stores in-transit purchases as an `orders` list per line. The previous single counter (`ordered` + `ordered-from`) is read as one purchase and converted on the next edit — nothing to migrate by hand.
