# TCG Binder 1.1.0

Quality-of-life release: card language support, a card grid view and searchable settings.

## Added

- **Card language** setting (English, Português, Español, Français, Deutsch, Italiano, 日本語 — via TCGdex). Card names, search and new card notes use the selected language.
  - **Name search is language-independent**: it queries your language *and* English, merged — "Caixa Secreta" and "Secret Box" both find the card.
  - Lookups fall back to English wherever a translation or scan is missing; card ids are identical across languages, so existing collections and decks are unaffected.
- **Card grid view**: toggle between list and card tiles in collections, decks and the search modal (button in each surface). Deck tiles show a quantity badge over the art; collection tiles show condition and the playset pill. A new **Default view** setting controls how surfaces start out.
- **Loading indicator** in the card search prompt while a request is in flight (static fallback under reduced motion).

## Changed

- Settings adopt Obsidian 1.13's **declarative settings API**: they now appear in the settings search, and the binder folder field uses the native folder suggester with inline validation. Older Obsidian versions (1.8.7+) keep the previous settings panel.

## Fixed

- Search results without a scan keep grid tiles aligned with a placeholder frame.
