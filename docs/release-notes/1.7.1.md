# TCG Binder 1.7.1

Uploaded images are no longer final.

## Fixed

- **Replace an uploaded card image**: cards with a user-uploaded image now show a "Replace image" button in the card viewer. The note's embed is swapped in place and the previous file goes to the trash (following your Obsidian deleted-files setting), so nothing piles up in the vault. Official scans from the card database remain untouched by design — the button only appears for your own uploads.
