# TCG Binder 1.2.3

Smarter name search.

## Fixed

- **Recent printings no longer get buried**: name results are sorted newest set first (the API returns oldest first), and the result window is much larger — searching "Switch"/"Substituição" now surfaces the current printing instead of cutting it off behind decade-old reprints.
- **Printed symbol abbreviations match**: queries are matched token by token, so "Rocky F Energy" finds "Rocky Fighting Energy" (works for all energy types), and accents are optional — "substituicao" finds "Substituição".
