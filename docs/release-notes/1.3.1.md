# TCG Binder 1.3.1

Correct card categories on non-English data languages.

## Fixed

- **Energies no longer show up as Trainers**: with the data language set to Portuguese (or any non-English locale), TCGdex returns the card category localized ("Energia", "Treinador") and it was stored as-is — so deck views grouped those cards under Trainers and decklist exports put them in the wrong section. Categories are now normalized to their canonical form across all supported locales, both when fetching new cards and when reading notes that were already created — existing notes are repaired automatically, no re-import needed.
- **Basic energies from localized notes respect the copy-limit exemption**: cards hydrated in a non-English locale were missing the basic-energy flag, so deck validation wrongly flagged more than 4 copies of a basic energy. The exemption is now derived from the normalized category and, as a fallback, from the card's canonical English name.
