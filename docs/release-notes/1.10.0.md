# TCG Binder 1.10.0

Where is that card? One search box answers it.

## Added

- **Global search on the dashboard**: type a card name and see every copy you own across all collections — quantity, variant and condition per line — plus every deck that plays it. Each result links straight to its collection or deck, and clicking the card opens the viewer to flip through the results. Accent-insensitive and it matches the English name too, so "water energy" finds your localized "Energia de Água". Fully offline.
