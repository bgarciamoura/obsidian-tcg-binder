# TCG Binder 1.20.0

Arrange the dashboard your way.

## Added

- **Drag-and-drop reorder**: drag any collection or deck on the dashboard and drop it onto another item of the same section to take its position — works in both the list and the two-column layouts. The position is stored as `sort-order` in each note's frontmatter, so the order survives reloads, syncs with the vault and follows renames; notes without one sort last, A–Z. The chosen order applies everywhere the plugin lists collections and decks (global search, collection pickers, …).

## Notes

- Reordering uses native HTML drag events, so it is desktop-only; mobile shows the persisted order.
