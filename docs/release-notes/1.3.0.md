# TCG Binder 1.3.0

Collection management grows up: acquisition dates, smarter ownership matching, and quality-of-life actions.

## Added

- **Acquisition dates**: every card records the date it actually entered a collection (`added` in the entry) — stamped on adds, imports, and when a set-checklist line gets its first copy. The collection view gains a **period filter** (last 7/30/90 days) and **date sorting** (newest/oldest first).
- **Search by printed number**: type the fraction printed on the card — `194/198` — and the set is identified by its printed size.
- **Move between collections**: a new row action moves a card line to another collection, preserving quantity, variant, condition and the original acquisition date (merging if the destination already has it).
- **Remove from the grid**: card tiles now have an inline remove button over the art.

## Changed

- **Ownership matches the game's rules**: "Missing from collection" and the playset indicator now aggregate by card *name* across every printing and collection — owning Switch from one set satisfies a deck line for Switch from another.
- **Cross-language identity**: card notes store the canonical English name (`name-en`) when created in another language, so a collection in Portuguese and a deck in English still recognize each other. Existing notes are backfilled by "Fetch missing images".
