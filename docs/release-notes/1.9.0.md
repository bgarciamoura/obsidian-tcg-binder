# TCG Binder 1.9.0

Every variant a collector tracks, and a search that finds what exists.

## Added

- **Eight new card variants**: League and League foil, Poké Ball and Master Ball reverse patterns, 1st edition and 1st edition holo, Prerelease and Staff — alongside the existing Normal, Holo, Reverse holo and Promo. Available everywhere variants appear: adding cards, inline editing, filters, quick add and variant lines.

## Fixed

- **Name search no longer misses existing cards**: searching a name whose words are common across an archetype (e.g. "Energia da Equipe Rocket" among 171 "da Equipe Rocket" cards) could return nothing because the wanted card sat beyond the API's first result page. Multi-word searches now match the full phrase first and the fallback scans additional pages.
