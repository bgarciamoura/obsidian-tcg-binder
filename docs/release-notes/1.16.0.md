# TCG Binder 1.16.0

Copies you buy for a deck stay with that deck.

## Added

- **Per-deck allocation**: adding missing cards to a collection from a deck's screen now marks those copies as that deck's. They are guaranteed to it in the missing math — another deck that runs the same card can no longer absorb them — and they are reserved from other decks even while the deck is still being assembled. The missing list explains it inline: "4 in collection · 3 reserved by other decks · 2 reserved for this deck".
- **Dashboard layout toggle**: a button next to the title switches the collections and decks sections between the classic list and a two-column grid (persisted; narrow screens stay single-column). Grid rows share one height, keep covers at a slimmer 42%, and give the name its own line so it never gets squeezed out.

## Fixed

- **Missing list merged printings into one row**: same-name deck lines (2× Hoothoot SCR + 1× Hoothoot PRE) showed as a single row with the first printing's art and price, so editing the split looked like the list never updated. Availability is still pooled by name — any printing satisfies the deck — but each printing now renders its own row with its set code, its own price, and an add button that targets that exact printing.
