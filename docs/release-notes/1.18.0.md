# TCG Binder 1.18.0

Track the hunt: what you bought, what's on the way, and which decks you're building.

## Added

- **Shopping tracker**: buying a deck's cards over time no longer means buying twice. A cart button on every missing card records "N bought, on the way" (partial amounts welcome); the row's big number becomes what you still have to BUY, fully-bought lines dim out, and cost-to-complete plus the wishlist button ignore copies already purchased. Registering the arrival (the + button) burns the on-the-way count down automatically. A summary tile shows the total on the way.
- **Coverage badges**: deck lines the collection can't fully cover yet show a subtle "2/4", with the on-the-way detail on hover — the whole deck reads as a build checklist.
- **Deck status**: the assembled toggle grew into a three-state lifecycle — Assembled (physically built, reserves its full list), Building (actively hunting cards) and List (just a reference; non-assembled decks reserve only copies bought for them). The dashboard flags each deck: green "✓ Assembled" pill, orange "Building" pill, nothing for plain lists. Marking copies as bought on a plain list auto-promotes it to Building — buying activity is the signal. Imports start as List.
- **Rename from the UI**: a pencil button on collection and deck headers renames the note in place — wikilinks update, name collisions are refused.
