# TCG Binder 1.5.0

Register a shoebox of cards in one sitting.

## Added

- **Quick add by set**: a new command for entering physical cards fast. Pick a set once, then just type the collector number printed on each card — a live image preview confirms the match, Enter adds it and clears the field for the next one. After the first fetch the whole set is cached, so every lookup is instant and offline.
- **Entry syntax**: `45x3` adds three copies; a trailing `r`, `h` or `p` marks reverse holo, holo or promo (combinable in either order — `45x3r`). Collection, variant and condition defaults stick between cards and sessions.
- **Batch paste**: paste a whole run of numbers (`45 67, 112x2 8r`) and they are added in one go. Numbers that don't resolve stay in the input for correction — what was added never re-enters, so nothing gets double-counted.
- **Change set without leaving the flow**: one button swaps to the next pile's set and keeps going.
