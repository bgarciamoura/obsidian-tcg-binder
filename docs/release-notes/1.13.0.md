# TCG Binder 1.13.0

Every card now tells you where it is committed.

## Added

- **"Reserved for" on the card detail**: opening a card shows every deck that runs it — "1× Mega Lucario", "1× Mega Excadrill · Not assembled" — matched by functional identity, so any printing of the same name counts, exactly like the reserve math. Decks that are still just lists appear dimmed: they want the card but hold no copy. With "Reserve deck copies" off, the label is a neutral "In decks".
