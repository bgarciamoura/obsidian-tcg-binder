# TCG Binder 1.14.0

Every Pokémon lands in the right type collection.

## Fixed

- **Split kept creating a generic "Pokémon" collection**: notes freshly stamped by the types backfill were re-read before Obsidian had reparsed them, so they still looked typeless and fell into the generic bucket. The split and "Own all" flows now use the stamped types directly — a card whose set data knows its type always lands in its type collection.

## Changed

- **Natural pt-BR collection names**: Pokémon Elétricos (was "Pokémon de Raios"), Pokémon Normais (was "Pokémon de Incolor"), Pokémon Psíquicos and Pokémon Sombrios; the other types keep the "Pokémon de ..." form. Each per-type name now has its own locale key.
- **Hardened type matching**: accent- and case-insensitive lookups plus videogame-style aliases (Normal → Colorless, Electric, Dark, Steel/Aço, Escuridão/Noturno) — localized or unaccented type values can no longer dodge their bucket.
