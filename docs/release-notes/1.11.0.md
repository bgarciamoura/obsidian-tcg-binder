# TCG Binder 1.11.0

Register everything in one place — let the plugin sort it.

## Added

- **Split collection by type**: a new command takes one mixed collection and moves every card into a collection per type — Items, Supporters, Stadiums, Tools, basic and special energies, and Pokémon grouped by their energy type ("Fire Pokémon", "Grass Pokémon", ...). Your existing type collections are reused by name, missing ones are created, and quantities, variants, conditions and acquisition dates travel along and merge cleanly. Cards the plugin can't classify stay where they are, and the command is safe to re-run: register new cards into your inbox collection and split again — only the new ones move.
