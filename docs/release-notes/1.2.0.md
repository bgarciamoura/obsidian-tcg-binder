# TCG Binder 1.2.0

Fixes for two 1.1.0 issues and a new image-backfill tool.

## Added

- **Fetch missing images** (dashboard button + command): scans card notes without an image and backfills them from the card database — useful when a scan is published after you added the card. The note body only gains an embed if it has no image yet; your notes stay yours.

## Fixed

- **Images broke with a non-English card language**: TCGdex advertises localized image paths (e.g. `/pt/`) that don't exist on its CDN. All image URLs are now normalized to the always-available English scans — card names, search and set names remain localized.
- **List/grid toggle overlapped the search input's clear button** — moved to the left of the input.
