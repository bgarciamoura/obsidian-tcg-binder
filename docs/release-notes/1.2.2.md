# TCG Binder 1.2.2

Better images for cards the card database doesn't cover.

## Added

- **Second image source in the backfill**: when TCGdex has no scan, "Fetch missing images" now probes the pokemontcg.io image CDN (no API key involved) and uses it when the scan exists — every URL is verified before being written to a note. Fills most basic energies and older promos.
- **Card-back fallback**: cards with no scan anywhere (e.g. brand-new promo sets) now show the classic card back instead of an empty placeholder — in collection tables, grid tiles and search results. Embedded in the stylesheet, so it works offline. Once a scan is published, "Fetch missing images" replaces it with the real art.
