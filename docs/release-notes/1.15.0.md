# TCG Binder 1.15.0

Covers from anywhere, and imports that know they are just lists.

## Added

- **Cover from an external image or upload**: the cover menu now offers three sources — pick a card from the list (as before), paste an external image URL, or upload a file from your computer (stored inside the vault, in the binder's `covers/` folder). Position adjustment and removal work the same for all three, and replacing an uploaded cover trashes the old file automatically.
- **"Assembled" choice on deck import**: the import modal gets the same Assembled toggle as the deck view, starting OFF — an imported decklist is usually a netdeck you have not built yet, so it no longer reserves collection copies the moment it is created. Tick it when you are importing a deck you physically own. (Shown only while "Reserve deck copies" is on.)
